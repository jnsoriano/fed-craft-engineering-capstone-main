## Project Brief

Your team has been engaged to build EventCraft, a modern event planning wizard for a premium events company. The application enables corporate planners, couples, and gala organizers to configure and book events through an intuitive two-step flow.

The wizard guides users through selecting an event type, defining logistics (date, time, guest count), setting a budget, choosing equipment and services, and completing their booking. A persistent budget tracker provides real-time feedback as selections are made, using a traffic-light system (green/amber/red) to keep users informed of their spend.

Your deliverable is a fully functional React/Next.js implementation that matches the provided designs and follows the specifications in the FSD and TSD. The application should persist form state across browser refreshes, validate inputs in real-time, and provide a polished, accessible user experience across desktop and mobile devices.
